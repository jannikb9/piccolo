## Install

```bash
curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/jannikbertram/piccolo/main/install.sh | sh
```

Piccolo offers new versions itself when they come out (before 0.2.0, run the command again).
